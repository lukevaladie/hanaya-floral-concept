# Hanaya Floral Design — independent website concept

A bespoke React design exploration by Valadie Digital. Not commissioned, endorsed by, or affiliated with Hanaya Floral Design. The official site is https://www.hanayafloral.com/.

## Run and build

Requires Node 22 or later. Run `npm install`, then `npm run build`. Serve the directory using any static HTTP server. The committed `index.html`, `app.js`, `app.css`, and license notice are deployable on GitHub Pages from main / root. Relative paths support a repository subpath.

Source: `App.jsx`, `styles.css`, `build.mjs`. Compiled React is bundled locally. Fonts use Google Fonts (DM Sans and Italiana, with system fallbacks). All botanical illustrations were created expressly for this concept with SVG, and do not represent Hanaya's work or products. No third-party portfolio photos or logos were copied.

## Behavior and privacy

Service buttons update explanatory content. Palette controls change a conceptual illustration. Mobile navigation is keyboard accessible. No forms, bookings, data collection, analytics, local storage, or outbound submissions. Links to the official business are labeled. A prominent notice identifies the independent concept; `noindex,nofollow` discourages search indexing.
